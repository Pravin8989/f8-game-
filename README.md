# F8 Game Website

Black & Gold responsive website with five pages and a shared header/footer.

## Files
- `index.html` — Home page with automatic four-image carousel
- `about-us.html`
- `privacy-policy.html`
- `disclaimer.html`
- `faq.html`
- `style.css`
- `script.js`
- `images/` — replace image placeholders with your own images

## Add your images
Place your images in the `images` folder using these exact filenames:
- `f8-main.jpg`
- `f8-1.jpg`
- `f8-2.jpg`
- `f8-3.jpg`
- `f8-4.jpg`

Use images you own or are authorized to publish. The pages will still load, but image areas will be blank until you add them.

## GitHub Pages
1. Upload all files and the `images` folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under Build and deployment, select **Deploy from a branch**.
4. Select your `main` branch and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

Before publishing, update policy text and contact details to match your actual website and services.
